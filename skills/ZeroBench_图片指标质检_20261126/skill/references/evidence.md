# 本地案例怎样影响质检

时间：2026-11-26。下列是固定版本的历史记录，不是此次新跑模型结果。完整路径以cowork项目为根；活动目录可能继续变化，应读取快照后再引用数量。

| 案例 | 已知证据 | 应形成的规则 |
|---|---|---|
| 难题300报告 | 选入的是低正确率题，样本不覆盖全部难度总体；原图密度/熵和失败并非可靠单调关系 | 不以该选择样本训练“全体模型难度”阈值；按题型内比较，报告样本分母 |
| S20-18/19 v3 | 历史工具开放下各4轮错答；局部测距字段正确，最后采用的状态/类型/权重差异可复算末答 | 优先多属性对应及其联合使用；不能概括成模型不会量距离 |
| NR10最新版四轮 | 历史快照40轮：13完整正确、0完整错答、23超时、4中断；NR04和06各4轮正确 | 真实图也可能简单；一个大裁图/静态属性表就够的题不靠加算式伪装视觉难度；未完成不计错答 |
| ZB10-06/v2 | r2最后D_move_tot=164，标准165；16/17字段正确；旧跑法no_tools=true | 只凭差1不能指认某细胞被读错；不算工具开放验证 |
| ZB10-10/v2 | r1部分优化字段错，r2冲突计数及后续集合/优化字段错；旧跑法no_tools=true | 按轮分辨状态演化/计数/优化，不能统一归因到一个图点 |
| ZB10-09/v2 | r3给出部分正确字段及带?向量，标needs_review | 残缺向量、推理token多、矩阵求逆费时，不证明视觉失败 |
| ZBN05/07 | 真实序列或PWM参与构造，凝胶/EMSA视觉由程序生成 | 标模拟观测图，不能冒称真实实验原图 |
| ZBN08 | 组合真实金相素材与计算谱图 | 分面板来源；真实金相与模拟谱图不能假定来自同一样品实验 |

## 达标记录的最小链

原图和版本→事实表→标准求解器及输出→模型实际可见输入与工具设置→完整末答→逐字段判分→错误归因。平台1–3点记录关键证据，不用全部作者测量坐标充当平台打点。无最后采用的事实表时，错误归因写“某字段错，原因未证实”。
