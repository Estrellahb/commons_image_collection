# 图源筛选建议

这里按当前“真实复杂图＋必要视觉配对＋可复算联合推理”的目标排序，非按网站是否返回200排序。网络可达和文件扩展名不能证明已经取到可用图；先解码、看原生尺寸和图证，再逐资产核许可。

| 优先级 | 来源 | 推荐图/考点 | GT及边界 |
|---|---|---|---|
| P1 | ShelfWise真实货架 | 近色异SKU、层间身份配对、价签归属、自然遮挡 | COCO有商品框和类别，不自带价签配对、镜像真假和隐藏库存真值；作者人工补标。已有14张本地样例优先复用分析，出新题需查排除集 |
| P1 | BBBC039 | 紧邻核、粘连边界、多对象与邻域约束 | 原始DNA单通道200视野，约23000核，520×696、16位；不能包装成现成时间序列或Z-stack。实例掩膜依官方颜色/标签解释，不能简单二值连通域计数。[官方说明](https://bbbc.broadinstitute.org/BBBC039)，CC0 |
| P1候选 | FSC-147 | 密集实物、相似干扰、跨区域筛选 | 点标注可支持目标类计数，不自动给全部物类、遮挡层别或框；先核图像资产许可，不从代码MIT推图片MIT。[作者仓库](https://github.com/cvlab-stonybrook/LearningToCountEverything) |
| P1候选 | IDR/其他真实显微序列 | 同一实验中的真实Z/时间/通道组合 | 逐数据集核坐标、通道、分割和许可；真实多层优先于模拟共聚焦 |
| P2 | COD | 带周期邻居的多层球模型、配位/占位→组成→密度 | 用真实CIF渲染并标明；展开对称等价位置、边界共享、占位率、晶胞体积；不是CIF行数=原子数。COD数据公开CC0，[官方镜像](https://cod.psdi.ac.uk/)。Cactus是分子图服务，不是晶体结构来源 |
| P2 | RCSB/PDBe | 多链界面、接触图、多视角空间筛选 | 保留assembly/model/altloc、缺残基和距离定义；屏幕投影不能直接代替Å；数据库结构并非实拍照片 |
| P2 | SDSS＋Gaia | 密集星场，多波段对应与角距离 | 星表记录≠图中可见点；需WCS/epoch/配准/饱和与混合源处理。SDSS图像CC-BY、发布数据另述见[官方图片政策](https://sdss.org/collaboration/image-use-policy/)；Gaia许可单独核对，不沿用旧表NC猜测 |
| P2，允许数据示意图时 | PGLib-OPF、WNTR | 多节点、弯折连线、开关/阀态→可达/水力计算 | 电网布局距离不是线路长度，N−1拓扑连通不代表潮流可行；管网长度从文件属性而非绘图间距获得。数值求解需收敛检查 |
| P2探索 | OpenFlights | 路线交叉、机场身份对应、受限网络规划 | 地理大圆距离基于坐标；航线文件需去共享航班/重复、统一有向性、核有效期。不是当前航班时刻表 |
| P3 | UniProt/InterPro/Ensembl/UCSC/JASPAR | 结构域、外显子和motif多面板映射 | 有真实注释/序列不代表有真实实验凝胶；参数图可作配套，单纯读logo最大列或查基因名降低投入 |
| P3 | NIST ASD | 已有真实光谱与谱线表相互消歧 | 谱线表不是实验谱；相对强度不可不加条件跨来源相加；从表画棒谱应标数据渲染 |
| P3 | Lichess、Sudoku Exchange、Brouwer Go | 可作规则/状态配套，优先真实盘面有可靠转写时 | python-chess验证合法走子不证明唯一最优；需限定目标并实际求解。SGF实战下一手不等于唯一最优解；数独唯一解不等于工具开放下高难；库的难度评级不是本模型实测 |

反光/镜像场景可拓展商店、服装店、健身房。要求能从几何或上下文判别实体，不凭“看起来像”推断。不要为加难删掉唯一判别依据。

许可登记至少包括资产页、许可原文、作者署名、修改说明与许可适用对象；代码、原始数据、图片、第三方引用面板分别核。200响应、研究可下载、目录标了CC，不等于可以把每张图放进平台题库。
