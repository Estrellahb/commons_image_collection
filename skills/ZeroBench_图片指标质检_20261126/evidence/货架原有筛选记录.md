# 真实货架图片与分层筛选

在 ShelfWise 原始 27,244 张照片中，先按 COCO 标注筛出 2,035 张，抽取 14 张原图和对应标注，再按包装近色、可辨认尺度与现场布局复核。当前优先 3 张，专题保留 2 张，备选 5 张，降低投入 4 张。原图分辨率为 1125×1500 至 1920×2560，含横幅图。可从 [逐图指标](shelf_metrics.csv)、[逐图目视判断](visual_review.csv) 与 [原始照片](images/) 按同一 image_id 查看。

## 程序选取

官方 ZIP 内 COCO 给出 2,054,882 个商品框。尺寸短边至少 1080 px，单图 80–200 框，至少 85% 的框属于已知 SKU，已知类别至少 12 个，框短边中位数至少 40 px。按图像 ID 升序列出通过项目，以 Python 随机种子 261126 抽 14 张。首次实际下载仅分段读取官方 ZIP 内标注与指定 JPEG，可以用本地完整 ZIP 和下面的命令复现同一筛选。两个脚本分别负责全量元数据过滤和已下载样图统计，使用现有 Python、NumPy、Pillow。

```sh
uv run --no-sync python filter_archive.py /path/to/SKUs_on_shelves_PL.zip .
uv run --no-sync python screen_shelves.py
```

- **目标密度**记录框数与每百万像素框数。可读性同时看框短边的像素中位数。包装后方完全遮住的库存无法从正面图推断。未知 SKU 与无法辨认的官方类别保留计数，身份和近色运算只使用已知类别。
- **近色异 SKU 邻居**先对商品中心的水平和垂直间距分别用两框平均宽度、高度归一化，欧氏范数不超过 1.8 的异类框成对。取每框中央 60% 区域，缩放至 24×24 后按通道求中位颜色，转 D65 Lab，两代表色 ΔE76 ≤ 12 记作候选。阈值用于本轮试筛，光照、背景和花纹都会影响指标。每对的产品名、位置、框 ID 和色差保存在 [近色对明细](nearcolor_pairs.json)。
- **遮挡候选**计算两已知框交集占较小框面积的比例，≥0.15 计一对。这是矩形投影重叠，物理前后关系、镜像和剩余可见比例需回图判定。另记录距边 ≤1 px 的框。
- **文字与镜像**逐张目视检查，本批 14 张均未见大面积中文。波兰语包装可用颜色、瓶型、包装图案和局部词形消歧。玻璃反光可供研究，要求计数镜像实体时还需找到能把真实物体与镜像一一对应的几何证据。

## 读错图会改变排序的实际演算

取 22835 原图，以实际投影到图像 x 轴的距离计量。设 A 走向胡椒层最右的黑胡椒包（PIEPRZ CZARNY），B 走向同层最左的彩色胡椒包（PIEPRZ KOLOROWY）。两方案共用上一层两包姜粉（IMBIR）中的右包作为起点。基准成本 A=3、B=6，单位为题设成本。峰时仅对水平距离超过 80 px 的方案加罚，再回到姜粉行，读两包右邻第一个空纸托下的价签，黄底加 5、白底加 2。取成本较低方案。

| 从原图核查的证据 | 发布方标注或可见坐标 |
| --- | --- |
| 右姜粉包与左姜粉包 | ID 213696，中心 x=770.5；ID 213713，中心 x=679.0 |
| 最右黑胡椒与最左彩色胡椒 | ID 213796，中心 x=629.0；ID 213763，中心 x=719.5 |
| 第一只空纸托对应价签 | 原图约 (856,408)，黄色底。价签位置与颜色为目视复核，原 COCO 仅标商品。 |

正确读图时 A 距离 141.5 px，B 距离 51 px。基准选 A，峰时成本 8 和 6，改选 B。若错把左姜粉当起点，两距离成了 50 和 40.5，峰时仍选 A。若正确测距却把价签读成白底，峰时成本 5 和 6，也仍选 A。选中不同端点、误读远端局部标志，都足以改变同一个结论。阈值最近仍有 29 px 余量。名义中心采用 COCO 外接框，公开题若要求小数坐标，应给可操作的定框定义和容差；此配方仅以距离分档和排序判定。这是作者侧可复算示例，模型作答难度待实测。
