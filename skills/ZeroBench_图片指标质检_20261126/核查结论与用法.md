# 图片指标质检：本地核查与取舍

本次执行的是本地图片/标注计算，没有调用评测API、没有向平台提交，也没有安装环境。共读取14张真实货架照片及6张现有题图。

## 筛选结论

**优先继续：22835、13366、18049；专题储备：16067、27065。** 这些是素材候选，不是已经通过平台或已证明高难的题。现有场景曾用于分析，制作新题需按题号/图号/场景与排除集去重。

## 实际检出的问题

- 严格原始坐标检查：13项待复核，7项阻断。其中2项是COCO边界问题，5项是当前真实原图筛选口径下的模拟/示意图；没有读图输入异常。
- 22835的213800号框右端到1201，图宽1200；13491的713363号框右端到1602，图宽1600。按显式clip_visible策略只对计算使用可见交集，原文件不改，保留原框和修正记录。两项转为待人工复核。
- 修正策略后：15项待复核、5项因来源类型与真实原图要求不符而隔离。没有任何项目自动被标为高难达标。
- ZB10-06/09/10为软件题设图，ZBN05/07的关键实验表现由程序绘出；可进允许示意图/模拟图的另一类候选池，不能算真实原图。ZBN08为混合面板，需要单独核来源和同一样品假设。
- ZB10/v2历史轨迹工具关闭，另记nonconforming_or_unknown_tools；ZB10-09的残缺向量不列确认错答。

## 运行与查看

- 打开 `report/index.html` 看图和逐项理由；`report/metrics.csv`用于筛选；`report/report.json`包含配对清单、裁框记录和依赖图指标。
- `manifest.json`是当前可复现输入；`images/`为本次20张题图；`annotations/`保留原COCO子集。
- `evidence/22835_recompute.json`保存本次实际复算。
- `report_raw/`保留首次严格框范围检查结果。
- `build_examples.py`用于从本机已有目录重新采集初始样例，生成后需保留人工增补；它不是通用下载器。

```sh
uv run --no-sync python skill/scripts/inspect_images.py manifest.json --out report_rerun
```

从解压目录运行。仅使用已有Pillow、NumPy。不含API密钥。
