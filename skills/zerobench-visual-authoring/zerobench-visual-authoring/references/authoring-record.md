# 单题作者记录和平台字段

按同一题号、版本、最终图片尺寸整理以下材料。出题阶段可直接照表填写。需要机器可读样例时，参照[已填写的 S20-19 作者记录](S20-19-example.json)。它包含冻结题面、作者两段解答、46 个点和 18 个答案字段，适合查看怎样从一个读数追到具体小问。

## 从平台表单回到作者材料

| 平台所见 | 作者填写 | 答题者实际看见 |
|---|---|---|
| 主图、图像类型及细分、来源 | 原始来源与可用许可、署名、图号或数据 ID、呈现图尺寸与变换。多图写清面板和对应时点。真实数据渲染另存输入和视角，原创题设图保存生成依据。 | 题目所需的清晰主图或组图、必要图例与标尺 |
| 题型 | 取决定答案的主要操作作一级题型，图像细分标签另填。按该版平台的实际枚举填写。 | 作者可见 |
| 标签列表、逐对象打点 | 点编号、分组、对应面板、实体 ID、原图坐标、所指的可见细节。对关键参照点、参数表行、受影响对象及易混干扰留有定位依据。 | 图片中本来就有或题面已公开定义的符号 |
| `prompt` | 最少必要的判定条件、相关小问、单位、输出字段顺序，以及适用的容差和并列规则。 | 完整公开题面 |
| 出题思路 | 写明哪个可见细节决定哪一条关系，再怎样改变应答字段。 | 作者可见 |
| ① 图像识别（转文字） | 逐格或逐对象列出求解所需的观测值、定位与干扰辨析，覆盖所有用到的图内参数行。仅写“由图可知”时补具体读数。 | 作者可见 |
| ② 题目推理 | 从①和公开规则导出关系、约束、关键计算、去重与并列处理，直到标准答案。可选配图供审题人核对，两段文字仍须完整。 | 作者可见 |
| `response` | 唯一可匹配的答案或按约定规范化的多字段结果。附字段级真值、单位、判分方法和容差。 | 仅公布输出要求 |

本地记录的 `thinking` 为出题思路，`cot_image_understanding` 和 `cot_reasoning` 为作者写给审题人的两段解答。答题输入取干净的图与 `prompt`。包含打点、事实表、答案、已做过的例题和模型成绩的材料放在作者侧。平台字段的本地对照仅用于预览或填报，官方导入格式以实际接口为准。

## 按项目指南准备平台稿

题型按主操作选取。八种主类为计数聚合链、游戏／谜题规则求解、复杂指令遵循、小众知识解码、抗干扰文本读取、定位度量、拓扑／图结构追踪、空间变换。实拍密集场景照、规则盘面图、程序合成谜题图、拼贴复合图、实拍文字载体照、图示与专业记谱、软件界面截图是图片类别。词条显示与标点以填报页面为准，“跨层电阻”或“晶体测距”可写进题名或细分标签。

采集指南要求 1080p 以上原图，并在 100% 显示时检查关键细节。有三问以上时兼顾视觉元素、量化统计和空间关系。组图中每张图都应提供另一张图不能替代的证据。若题目用文字做识别、定位或计数线索，按一二检 SOP 选择英文文字，或改用可判读的数字、位置和图例。题干语言另按交付要求。图面及隐私处理遵循素材许可和数据规范，裁切不能破坏必需证据或署名条件。

## 打点怎么做

1. 以最终主图的原始宽 `W`、高 `H` 和左上角为坐标基准，同时记录点的像素位置。需要百分比时按当前本地预览的约定换算 `100x/W`、`100y/H`。每幅图使用自己的尺寸。裁切、旋转或缩放后重新映射坐标。
2. 一个点能说清“这一笔证据对应哪个对象、哪个属性”。同一晶体球露出的数片残弧可以属于同一实体。相交线上的几何交叉与实际接点应有不同图例。不要给作者后来加的编号赋予原图证据的身份。
3. 使用已有的颜色阈值、连通域、化学绘图坐标或 YOLO 等提议候选时，回原图确定归属，记录接受、合并、拆分、拒绝或补标。如果检测器找到四根权重条，还要确认四条都属于同一个编号对象。核对裁图时记原始像素框及它实际覆盖的部位。

## 求解及判分交接

| 作者保留的记录 | 应能回答的问题 |
|---|---|
| 事实表 | 在哪个面板、哪一处看见哪个 ID、属性、位置或刻度？完全遮挡、局部可见和易混对象各如何处理？ |
| 小问与答案字段对应表 | 每一问使用了哪些图事实，受哪些公开规则约束，返回哪个整数、实数、集合或编码？ |
| 正确输入的可复算解 | 一个方案由什么组成？对称或交换顺序怎样计？代表解如何选？能否从最终方案重新算出汇总值？ |
| 容差和误配复算 | 正常读数误差是否跨过边界？若把指定对象错认成旁边的一个，重新求解后哪项结论改变？ |
| 版本与作者状态 | 当前题号、父版、变动的图或规则、最终使用的标准答案、作者复算完成情况和对应试答记录。 |

整题要求多个字段时逐项判定。计数、ID 和编码用题面定义的精确口径。单位和容差各自属于具体字段，`3` 与 `3.0` 对普通数值等价，固定宽度的编码保留前导零和顺序。无序集合按题设去重或排序。如果题目的最优解天然有并列，返回最优解数、可接受解集合或按公开规则选出的代表。解析有歧义时标记待判分，避免从中间过程拼凑终答。

## 测试与判分记录

2026-11-26 查看的平台首轮样本显示 4 次试答，四次全对会退回提难。页面显示图加题面作为难度输入，作者配图可选、最多 3 张。系统提示、工具清单和时间预算的部分内容不可见。本地若已获授权做平台对齐，记录实际模型回显、推理档、轮数、工具、单轮时间及响应步数。用户指定各测两次时按两次执行。端点、并发和密钥属于该次运行配置，保持在 skill 之外。

记录整题正确、可判分错答、待判分和没有有效完整答案的数量，并保存已有的逐字段结果、收据及工具返回。无有效答案再注明超时、步骤上限、服务或传输错误等实际原因。作者的错读演示、同题改版和外部榜单各有自己的证据。修订图或规则后，用新版题号和结果追踪。

同一逻辑轮因连接中断而恢复时，保留原记录和已耗预算。最终返回完整答案的，只计一次试答。多个小问和多个字段都属于同一轮。若用户需要单独考察推理，可以把作者事实表与公开规则做成纯文本诊断输入，另记是否实测及其结果。
