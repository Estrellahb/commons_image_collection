# ZeroBench 视觉联合推理出题

2026-11-26 整理，已纳入 S20 原版、v2 和 v3 的本地实测。

先回答一个问题。**答题者必须从图中区分哪两个对象或哪两种读法，这个区别会改变哪条关系，又会改变哪个答案？** 能具体指出这三件事，再去找图、定规则和计算。适合的题目既允许裁图、放大和编程，也要求答题者把读到的事实用在正确的位置。

## 投入优先级

| 优先级 | 选什么题 | 落到题目上 |
|---|---|---|
| **P1** | 密集相似对象的身份、层别、状态、类型、权重或通道需要逐一对应 | 同一对象的多个属性共同决定可用边、参数组或局部代价。设计一个可辨认的例外，漏掉它会改变所求量。 |
| **P1** | 元素间测距与其他属性共同形成关系 | 先认出从谁量到谁，再按距离和层别选参数，或按距离和类型建立兼容、互斥关系。让不同配对产生不同计算结果。 |
| **P1** | 整张图共同约束的计数、优化和排序 | 明确什么算一个完整方案，用同一套事实求合法总数、最优值、并列数或代表方案。若考排序反转，保留判断反转所需的两工况数值。 |
| **P1，有相应图证时** | 真实仪器的模式与刻度对应、密集目标中的完整筛选 | 先辨认有效通道、量程、轴或符合条件的实体，再做校正和聚合。把可见事实与最终汇总对应起来。 |
| **P2** | 跨时相或多视角身份对应、细支路与交叉、阶段更新 | 让另一面板、局部连接或前一阶段的状态消解歧义。留意裁图坐标和实际覆盖对象。新题按本题结果定难度。 |
| **P3，探索** | 公考图形规律、隐藏表示、条件迁移 | 先界定允许的规则族，用盘面中的决定性格子排除最相近的另一种规则，再求新格。 |

**降低投入**的题包括仅删 caption 后读明显趋势、清楚给出对象和参数后的常规代入、只量一段有明确标尺的距离、只扩展重复晶胞或增加相同符号，以及只问一个赢家。它们可以作为递进题的一步。优先把制作时间花在会改变可行集合、参数或最优决策的图像差异上。

S20/v3 的两道固定题各有四份可判分末答，整题全对 0/8。局部测距字段八轮都正确，四轮也答对了反转。八份末答均可由最后录入的状态、权重或类型差异复算出来。由此支持的投入方向是多属性登记及其后续使用。旧版、难题 300 和论文各自能支持的结论见[证据与适用范围](references/evidence.md)。

## 选图与建立事实表

1. **按用户的素材要求选来源。** 优先取明确允许使用的真实观测、实拍、扫描或论文原图。使用真实 CIF、PDB 或测量数据绘图时，标注为数据渲染并保留输入与视角。用户允许软件构造时，可以画题设模型、网络或规则盘面，标明来源，保存能重建图与答案的参数。若指定真实原图，找不到合格素材就换候选。数据库入口、能直接筛的字段和需要看图判断的条件见[图源指南](references/image-sources.md)。
2. **在实际题图上建立作者事实表。** 每个参与求解的对象有稳定编号、可见位置、观测值、纳入或排除理由，以及它控制的参数或关系。保留自然遮挡、层叠、反光、近似标记等有辨析价值的图证。涉及遮挡计数时，写清完全可见、部分可见和完全遮挡的口径。用检测框或颜色分割提候选，逐个归并属于同一实体的碎片，检查漏标和错配。
3. **把题面收紧到刚好能解。** 保留决定意义的面板、图例、标尺、方向、单位、物理假设、边界等号和并列规则。将直接说出对象归属、趋势或赢家的 caption 句子留在作者材料。论文事实与另加的工况分别标明。题面给可选参数和选择规则，把选择哪一行、哪一组邻居跨层留给图。新题按用户指定的排除集去重，包括难题 300 和已给题包。核对来源 ID、论文图号、观测场景及衍生裁剪，同一来源的重裁或换视角要标明。

## 把测距接进 4–6 个递进小问

按“读图元素 → 分析关系 → 解答或高级推论”设计。用户要多问联合计算时，可用下列六问作骨架。按题材合并自然重合的小问，每个输出都应有诊断或决策价值。

| 小问 | 要答题者做什么 | 可判分的输出示例 |
|---|---|---|
| ① 读对象 | 分辨相似实体，读图例和状态，定位标记中心、基准点与实际工作模式 | 有效容量、对象 ID、端点或有效通道 |
| ② 量元素间距离 | 用同一标尺测指定对象对。写清用中心、边界、投影、空间距离还是沿图的路径长度 | 平方距离、跨层邻居、最近合格对象 |
| ③ 建关系、选参数 | 让距离与类型、层别或状态共同决定连接、冲突和取参 | 两方案的兼容边数、无序冲突对、适用参数组 |
| ④ 解全局问题 | 联合使用容量、互斥、共享边界、守恒或周期条件，要求全部合法方案或目标量 | 可行方案总数、晶胞密度、有效电阻或工况值 |
| ⑤ 受限优化 | 定清操作预算、可更改对象、计数单位和并列规则，再优化 | 最优值、最优解数、最优边对 |
| ⑥ 给出高级结论 | 从同一套解导出排序、反转、稳健性或按公开规则选出的代表方案 | 两工况赢家及反转位、字典序最小的最优方案 |

给测距指出能在原图定位的起点、终点和单位。离散网格可声明如何吸附到格点。连续量要估计读数误差，并核对它是否可能跨过阈值或翻转赢家。若图只表达连通关系，就用沿边步数等有意义的量。用户明确要求物理测距时，应选带尺度的图或补足标定。各学科的做法见[测距、晶体、显微、遥感与盘面配方](references/construction-recipes.md)。

## 冻结题面与答案

- **算一次正确输入，再换一个有图证的混淆读法。** 保持其他条件一致，重新建关系、选参数并求解。若主问是“是否反转”，该误配应改变反转结论。若主问是完整计数或最优方案，应改变对应字段。正常测量误差下答案仍应稳定。把这项作者复算与模型实际发生的错读分开记录。[三份带图例题](references/worked-examples.md)
- **固定每个输出的含义。** 区分无序对和有序对、终态和历史、合法总数和最优解数。存在多个最优解时，给出并列数或规定代表解的排序。计数按整数比较，比值、距离、功率分别写单位及容差。固定宽度编码按字符串保存，保留前导零。整份答案和逐字段结果均可检查。
- **分别制作答题材料与作者材料。** 答题者看公开题面与主图或必要的组图。作者另存真值、求解方法、出题思路、按原图坐标登记的分类打点和两段解答。第一段逐对象或逐格列出求解必需的读数及干扰辨析，第二段从这些读数推出约束、计算和最终答案。[平台字段与填写示例](references/authoring-record.md)

## 用实测结果返修

按用户指定的模型、推理档、轮数和工具条件执行已授权的试答。平台对齐与本地自测要注明实际可见的设置。出题、模型试答、外部提交通常是不同请求，遵循当前授权。只整理 skill 或题目时，以本地作者材料交付。

看一轮失败时，先定位最终采用的事实表。裁图后已经改正的数值留在自纠记录里。把仍然错误的事实交给作者求解器。如果能复现末答，记录具体错读以及受影响的字段。如果事实正确而结果仍错，再查计数、优化和汇总。只有末答时，只定位可见的字段差异。保留题版、有效作答分母及超时、步骤用尽、传输故障、工具执行异常和待判分记录。换图、换关键规则或判分语义后另记版本。
