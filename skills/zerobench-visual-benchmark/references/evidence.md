# 证据账本：哪些结论已经支持，哪些仍是候选

本文件整合截至 2026-11-26 的本地题面、原始回执、工具轨迹、作者重放与既有论文研究。它用于决定出题投入，不是 GPT-6.2 Sol max 的无偏能力榜。当前用户已停止 C40 测试；本文件没有发起新模型请求，也不将未完成试次视为失败。

## 1. 证据分级与使用边界

| 层级 | 所需证据 | 可以支持 | 不能支持 |
|---|---|---|---|
| E1：具体机制已定位 | 冻结图与题面、可判分末答、实际工具输入、正确 GT、将最终错误图事实送回 solver 后重现差异 | 对该题版中的读图、配对、状态或计算错误作具体归因；形成 P1 设计方向 | 将两道题的错误率推广为真实照片、整个学科或模型总体弱点 |
| E2：有效字段差异 | 图题可解、判分口径已审，但只有末答或过程不足 | 某字段在该设置下出错；形成待定位候选 | 反推模型一定看错哪个像素或采用哪个内部算法 |
| E3：对照成功或合法工具解法 | 冻结题面、完整成功轨迹、工具权限已知 | 当前构造可被该路径解决，降低继续堆规模的投入 | 宣称该领域永远简单，或将合法裁剪、模板匹配称为作弊 |
| E4：机制建议 | 论文、相邻型号结果、未测试作者方案 | 选择素材、设计对照、提出 P2 假设 | 替代目标模型的实际错答证据 |
| X：能力结论不成立 | 内容错误、规则不公开、答案泄露、服务故障、超时、用户中止或缺末答 | 记录质检/基础设施问题，修复或保留未决 | 计入有效模型 fail 或用作困难题产率 |

同一题的多个错字段只计一次试答失败。重试历史不是新的独立试次。不同版本、工具权限、预算、服务通道和题面必须分开统计；脚本中的 `incorrect` 或 `banked` 是候选标签，内容复审优先。
