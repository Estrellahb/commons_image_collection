B 组（中部蓝柄区，H5–H12）：最前面悬挂蓝柄黑头 Park Tool 扳手的 8 个挂钩。 二、单钩视觉属性定义 对每个挂钩 Hi（i = 1..12），按原图实际可见工具逐钩读取以下属性： 1. 正面规格 size_i（单位 mm）：该挂钩最前一把扳手正面印刻的规格数字（H1–H4 读银色钢柄上的两位数字；H5–H12 读蓝柄上方椭圆框内的数字）。 2. 蓝柄把数 B_i：该挂钩上挂有的蓝柄黑头扳手总把数（含叠挂在后方的蓝柄扳手，按独立蓝柄顶部圆拱/蓝套层数计数；A 组 H1–H4 为 0）。 3. 红柄把数 R_i：该挂钩上挂有的红柄橙颈扳手总把数（包含同钩叠挂在后方的红柄扳手，尤其注意 B 组蓝柄后方可能叠挂的红柄扳手，按独立橙色颈圈/银色钳口/红柄层数计数）。 4. 单钩总把数 T_i = B_i + R_i。 5. 品牌后缀标识 U_i（仅对 B 组 H5–H12 定义）：若该挂钩最前一把蓝柄扳手正面白色品牌字样末尾印有 “USA”（即 “Park Tool USA”），记 U_i = 1；若仅印有 “Park Tool” 而无 “USA”，记 U_i = 0。 6. 钩心基准横坐标 x_i（单位 px）：取红色挂钩金属杆穿出该挂钩最前一把扳手挂孔处的中心像素横坐标。两挂钩 a、b 之间的水平像素投影距离定义为 dx(a, b) = |x_a -
