二、单物种块视觉属性定义
对每个物种块 i ∈ {A1..A6, B1..B6}，逐项读取以下整型属性与位置坐标：
1. 纸卡数 C_i：该物种块内的独立矩形标本纸卡张数。
2. 虫体数 S_i：该物种块内全部纸卡上装帧的甲虫总个体数。
3. 下端插针卡数 B_i：该物种块中，金属固定针插在纸卡下端（甲虫尾部下方）而非上端（头部上方）的纸卡张数。
4. 双字母墨水代码卡数 L_i 与 WX 代码卡数 WX_i：统计该物种块内，纸卡右上角手写有黑色双字母大写墨水代码的纸卡总张数 L_i，以及其中代码明确为 “WX” 的纸卡张数 WX_i。
5. 性别符号卡数 X_i：统计该物种块内，纸卡左上角标有性别符号（♂ 或 ♀）的纸卡张数。
6. 标本块平面中心 (cx_i, cy_i)（单位 px）：取该物种块全部标本纸卡联合外接矩形（不含下方印刷种名纸签）的几何中心坐标；任意跨组物种块对 (a, b) 的正射平面欧氏像素距离定义为 d(a, b) = sqrt((cx_a - cx_b)^2 + (cy_a - cy_b)^2)（单位 px）。

三、兼容边、合法方案与两工况代价规则
1. 跨组兼容边：跨组物种块对 (a, b)（a ∈ A，b ∈ B）成为兼容边，当且仅当同时满足：
   (1) 平面欧氏像素距离 d(a, b) ≤ 1490 px；
   (2) 两块下端插针卡数之和 B_a + B_b ≥ 3。
   其中 d(a, b) ≤ 733 px 称为“近距边”，733 < d(a, b) ≤ 1490 px 称为“中距边”。
2. 合法两对抽检方案：两条兼容边组成的无序集合 S = {(a1, b1), (a2, b2)}，满足端点互不复用（a1 ≠ a2 且 b1 ≠ b2），且所选 4 个物种块的性别符号卡总数 X_tot = X_{a1} + X_{a2} + X_{b1} + X_{b2} ≥ 1。
3. 虫体规模分组：记方案所选 4 个物种块的甲虫总个体数为 S_tot = S_{a1} + S_{a2} + S_{b1} + S_{b2}：
   - 大样本组 M：S_tot ≥ 44；
   - 精简样本组 N：S_tot ≤ 43。
4. 两工况代价（均为精确整数，越小越优）：
   - 动线费 walk(e)：近距边为 10，中距边为 30。
   - 记方案所选 4 个物种块的纸卡总数 C_tot、下端插针卡总数 B_tot、双字母代码卡总数 L_tot、WX 代码卡总数 WX_tot，以及全 12 个物种块的下端插针卡总和 sum_B：
   - 工况 0（常规纸卡扫描与跨栏移动成本）：
     C_0(S) = C_tot + walk(e1) + walk(e2)。
   - 工况 1（全虫体复检、下端插针补检与代码核验综合成本）：
     C_1(S) = S_tot + walk(e1) + walk(e2) + 2 × (sum_B - B_tot) - 6 × WX_tot - 2 × L_tot。
5. 赢家与并列规则：各工况下比较 M 组与 N 组最小代价，严格更小者为赢家（某组无合法方案则另一组胜；相等记 TIE）。两工况赢家均为 M 或 N 且不同时反转位为 1，否则为 0。方案规范编码写为 “a1-b1;a2-b2”（按 A 组编号升序），并列取字典序最小者。

四、请依次作答以下 6 个小问
1. 全 12 块盘点：依次输出全 12 个物种块的纸卡总数 sum_C、虫体总数 sum_S、下端插针卡总数 sum_B、双字母墨水代码卡总数 sum_L、WX 代码卡总数 sum_WX 以及性别符号卡总数 sum_X。
2. 跨组兼容边：输出兼容边总数 E 与近距边条数 E_near。
3. 合法方案计数：输出合法两对方案总数 P、M 组合法方案数 P_M 与 N 组合法方案数 P_N。
4. 工况 0 优化：输出 M 组最小代价、M 组并列方案数、N 组最小代价、N 组并列方案数。
5. 工况 1 优化：输出 M 组最小代价、M 组并列方案数、N 组最小代价、N 组并列方案数。
6. 赢家反转与代表方案：输出工况 0 赢家、工况 1 赢家、反转位（0 或 1），以及工况 1 赢家组最小代价的规范代表方案编码。
