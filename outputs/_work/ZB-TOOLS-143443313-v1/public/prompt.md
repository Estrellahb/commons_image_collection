把图中的红色工具盒当作一张取件图。只考虑带印刷槽标的三排批头，按上、中、下分别称为 A、B、C 排。每排从左到右用两位数字编号，从 `01` 开始。槽标是槽上方白圆里的符号和它右边的数字。每个批头按**插入的槽**归位。判色看靠槽口、围绕批头柄的色环。红和橙归为红类，黄归为黄类。

把棘轮扳手头部大黑圆盘的中心记为 L，把三排槽右下方单独横放的短金属件朝右露出的银色圆端面中心记为 R。批头的位置取所属槽标白圆的中心。所有距离取所述两点横坐标差的绝对值，单位为 4032 × 3024 主图的原生像素。若按缩放图测量，将横坐标按宽度比例换回。下列距离上限均含等号。

| 边 | 允许条件 |
| --- | --- |
| L–A | A 的色环为红类或黄类，且距离不超过 1680 px。 |
| A–B | A 已通过 L–A 条件。距离不超过 1490 px。B 的槽标白圆内若是六边形，两种 A 色环都允许。其余 B 槽只有在色环为红类或黄类、且与 A 不同类时才允许。 |
| C–R | C 的槽标白圆内是中心带白点的黑色六角星，且槽中批头的实际工作端没有单片宽直刃。距离不超过 1750 px。 |
| B–C | B 的槽标白圆内为六边形，或它的色环为红类或黄类。C 已通过 C–R 条件。距离不超过 1230 px。 |

一张取件单是一个依次取 A、B、C 各一件的三元组，四条边 L–A、A–B、B–C、C–R 必须都允许。积分为三个槽标的数字按 `A + 2B + C` 计算。一份双单方案由两张取件单组成。两单不能共用任何批头，交换两单次序算同一个方案。

把双单积分按从小到大记为 `(s,t)`。工况 M 的目标积分是 `(45,52)`，工况 N 的目标积分是 `(44,51)`。给定目标 `(u,v)` 时，方案偏差为 `|s−u|+|t−v|`，单位为积分。若要用同一份方案应对两种工况，先最小化两种偏差中的较大值，再在此前提下最小化偏差之和。

1. 四类允许边各有多少条？按 L–A、A–B、B–C、C–R 输出。
2. 完整取件单有多少张？
3. 双单方案有多少份？
4. 分别只考虑 M、只考虑 N 时，各自的最小偏差和达到该偏差的双单方案数是多少？
5. 同一份方案应对两种工况时，输出最小的较大偏差、在该条件下最小的偏差之和、同时达到这两个值的方案数，以及其中字典序最小的一份方案。

输出一行，格式为 `LA,AB,BC,CR|单数|双单数|M偏差,M并列数,N偏差,N并列数|较大偏差,偏差和,并列数,取件单1,取件单2`。每张取件单写成按 A、B、C 顺序拼接的六位字符串，保留前导零。两张取件单按字符串升序排列后比较整个字符串对。边数、计数、偏差和取件单编码均精确判分，允许用等值小数表示偏差。
