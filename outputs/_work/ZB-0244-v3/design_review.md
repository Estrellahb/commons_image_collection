# 构造前的三问

答题者必须区分A5零星残存浅色鳞片与A4成片青绿色主斑，区分C4奶油色后翅斑与C3、C5的橙红暖色斑，还须把C4斜向躯干对应到其自己的前后翅。

A5的F控制A—B允许边与单路线恰有一件F=0的条件。C4的H控制双路线八件H和恰为7的可行集，及工况1哪条路线接受4b加价。

可判分结果随之变化。A5误取F=1时，A—B边数、单路线数、双路线数、工况1代价和与代表向量改变。C4误取H=1时，双路线可行集为空。

# 题型与难度口径

主操作是从照片恢复多属性标本集合，再进行全部方案计数及受限双路线优化。题型使用counting、complex_instruction。候选库难度是hard。本次最终难度结合三次有效盲答的逐字段结果登记。题面不以计算规模或小问数宣称视觉难度。

当前公开题面允许一次完整读图、任意裁图、放大及编程枚举。每列胸部中心的排序确定编号。不同区域图证可以在一次正确转写中全部提取。去图和只读题面缺少F/H及列内成员输入，单个列裁图缺其余列及边界。较大整体裁图可保留全部图证。
